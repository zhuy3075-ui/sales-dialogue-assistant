## DEV01 只有一句“想做个系统”

**问题**：客户说要系统或AI，但没说解决什么。

**前置条件**：仍愿意讨论；尚未确认具体任务。

**执行步骤**：从现有材料找当前工作流程 → 只问最影响范围的一件事 → 整理一个业务目标，请客户核对。

**新拟回复**：你最想先省掉哪一步工作？拿最近一次实际操作说说就行。

**连续对话分支（模拟，结果未知）**：

- 客户：“客户讲了具体流程” → 用输入、处理、结果复述，不马上加功能。可接：“我理解主要卡在每天汇总这一步。我们先把这段对清楚，再看需要哪些功能。”
- 客户：“只说越全越好” → 先收敛首期，不承诺万能系统。可接：“可以先列想法，但第一版最好先解决最急的一件事。现在最影响你们的是哪一块？”

**边界与例外**：客户已有完整需求时不从头盘问；未验证不能回答“都能做”。

**反例压力测试**：把“越全越好”直接转换成固定低价全包，需求和成本均失控。

## DEV02 想自动化，但需求可能不成立

**问题**：客户认可技术，却说平时很少用。

**前置条件**：未成交；可以讨论使用频率和现有替代办法。

**执行步骤**：区分好奇与业务问题 → 核对任务频率和当前耗时，数据未知不补数 → 比较继续人工、现成工具或定制，允许不开发。

**新拟回复**：如果现在只是偶尔用，先不急着定制。你们目前多久会处理一次这类数据？

**连续对话分支（模拟，结果未知）**：

- 客户：“频率低且现办法可用” → 建议暂缓，不放大损失。可接：“那先沿用现在的办法更合适，等频率和工作量上来再看。”
- 客户：“每天反复做且有明确阻碍” → 回到最小任务范围。可接：“那我们先看最重复的那一步能不能简化，不必一开始把所有功能都做上。”

**边界与例外**：客户明确说以后自行联系时直接收尾，不再问频率；不根据时间节省直接承诺回本。

**反例压力测试**：为了推系统捏造人工成本，把一个月一次的任务说成严重经营损失。

## DEV03 数据采集能力还没验证

**问题**：客户要多账号自动采集，想先确认一定能做。

**前置条件**：平台、数据入口、授权和可获得字段尚未核实。

**执行步骤**：确认客户有权提供的数据与允许的访问方式 → 把可行性验证与正式开发分开 → 核字段、频率、失败处理与停止条件后再确认方案。

**新拟回复**：这部分我需要先核实数据入口和实际可获取的字段，不能现在就保证全部自动采集。先把能稳定做到的范围确认下来，再定方案。

**连续对话分支（模拟，结果未知）**：

- 客户：“有授权接口或可导出数据” → 用允许的样本核可行性，不要索要密码。可接：“可以先用脱敏样本或接口说明确认字段和流程，不用在聊天里发账号密码。”
- 客户：“要求绕过限制或保证永不封号” → 不承诺，改谈允许的数据来源或退出。可接：“账号安全和平台变化无法保证。我们只能按允许的方式评估，如果关键数据拿不到，就需要换方案或先不做。”

**边界与例外**：不将旧方案“每3账号1IP”当技术事实；具体平台规则和接口需现场核实，此卡不提供绕过限制的方法。

**反例压力测试**：未经验证就承诺全量实时采集、永不封号，把IP当作能力保证。

## DEV04 要现成工具还是定制开发

**问题**：客户有现成软件也能解决的需求。

**前置条件**：有清楚的必须完成任务；尚未确认方案适配。

**执行步骤**：先问现有工具具体卡在哪里 → 比较必要差异、总成本和维护责任 → 只为无法覆盖的部分讨论定制。

**新拟回复**：如果现成工具已经能完成主要工作，没必要为了定制再做一套。你现在用下来，最解决不了的是哪一处？

**连续对话分支（模拟，结果未知）**：

- 客户：“只是界面不喜欢” → 区分偏好和必要性，明确是否愿为差异付费。可接：“如果主要是界面习惯，可以先看看配置能不能调整，再决定值不值得重做。”

**边界与例外**：不臆测第三方功能和价格；不因卖定制而贬低所有现成工具。

## DEV05 用户喜欢，老板或合伙人没同意

**问题**：联系人认可，内部对必要性或费用意见不一。

**前置条件**：联系人是否愿意继续推动需先判断。

**执行步骤**：区分使用者认可与组织决定 → 根据原话找需求、成本、风险哪项未通过 → 愿意推进才整理一页内部说明；明确暂缓则结束。

**新拟回复**：如果你们还想继续评估，我可以把要解决的问题、交付范围和费用整理得更简明，方便内部讨论。

**连续对话分支（模拟，结果未知）**：

- 客户：“愿意推进但不知如何说明” → 只补内部决定所需信息。可接：“他们目前最拿不准的是有没有必要做，还是费用和后续维护？我们先补这一点。”
- 客户：“明确暂不需要，会自行联系” → 收尾，不绕过联系人。可接：“明白，那先不着急推进。之后需求明确了，我们再一起看。”

**边界与例外**：提到合伙人不等于联系人没决策权；不擅自联系老板，不把礼貌认可记为意向升级。

**反例压力测试**：联系人已表示暂不需要，仍逼其安排老板会议。
