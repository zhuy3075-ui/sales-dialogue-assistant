# 匿名来源与引用说明

本包是谈单诊断与销售知识助理的身份脱敏外发版。基础方法、模板、案例、证据编号保持稳定；作者和社群标识采用中性称呼。用户新提供的UC个案与LR局部经验仍独立存放，不装入通用包。

## 如何追溯

用scripts/knowledge.py get --id E编号取脱敏摘录、匿名来源编号、题名、日期及依据、段落、原保存行号、说话人角色。M卡关联E，T模板关联E，C案例保留段落与来源元数据。method-sources.json/md提供选定证据的前后文；source-catalog.json登记来源。未被选入的完整原件不在本包，不能声称在外发包内完成全部回看。

身份词已经替换，故所有引文都是“脱敏转录”，不能标作字节未变的原文。日期/段落/行号仍是内部采集时的定位信息，不是本说明文件的行号。历史SHA与核验描述仅追溯内部旧版，不证明外发字节一致。新版文件完整性见外发清单。

## 已移除与仍保留

已移除目标作者姓名/常见称呼、社群品牌、已识别联系方式、外部链接、私有磁盘路径；不包含原始截图、PDF、音视频、原压缩包、浏览器数据或私人用户案例。仍保留方法、内容、必要数字和时间，不把案例改造成通用有效性保证。

这是标识脱敏，不是对公开文章不可反向检索的保证；长摘录或独特案例仍可能被搜索匹配。如需不可反向识别的公开发布稿，应另行改写引用并降低原文可追溯性，两者不能同时无损保留。
